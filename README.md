# Room-Scanning-using-60hz-sensor
A 3D spatial scanning system built with an ESP32, 60 GHz mmWave radar, and 2-axis stepper/servo motors. Includes C++ embedded firmware for radar sweeps and a custom Python PyQt desktop visualizer for real-time point cloud rendering and spatial mapping.


#Here are the key advantages of your 60 GHz Pulsed Coherent Radar (PCR) module over ultrasonic and LiDAR sensors for 3D room mapping:

Better Material Penetration: Unlike ultrasonic sensors (which fail on sound-absorbing surfaces) or LiDAR (which struggles with glass, dark objects, and dust), radar penetrates light plastics, clothing, and environmental haze.

All-Weather & Lighting Independence: LiDAR degrades in bright sunlight, smoke, or fog, while radar works perfectly in pitch-black darkness and dusty conditions.

Complete Privacy: Unlike camera systems, radar measures spatial coordinates via radio waves without capturing any visual images.

Solid-State Durability: Unlike mechanical rotating LiDAR units with moving parts that wear out, your radar module is solid-state, handling vibrations and long-term use much better.
